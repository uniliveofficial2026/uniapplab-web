# Managed Secret Model

## Principle

**Never store or return plaintext secrets.** Stage D cloud MVP stores opaque secret references only.

## API

- `createSecretRef({ projectId, environmentId, name, actorId, plaintextForHashOnly })`
  - Input plaintext is used only to derive `secret://<sha256-prefix>` — not persisted
- `listSecretMetadata({ projectId, actorId })` — returns metadata without values

## Secret ref format

```
secret://<24-char hex digest>
```

Derived from `sha256(projectId:environmentId:name:material)`.

## Audit

`secret.ref.created` events recorded in cloud audit log with ref name and opaque ref — never the input value.

## Tests

`cloud.test.mjs` asserts listed/created JSON never contains the input plaintext string.

## Self-host

`@unilives/selfhost` writes only `CHANGE_ME_*` placeholder env vars at init — no production secrets generated by default.
