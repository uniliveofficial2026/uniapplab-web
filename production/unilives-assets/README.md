# production/unilives-assets

Authoritative **non-runtime** masters, previews, audio, models, textures, animations, and references.

- Do **not** place whole design boards in runtime (`artifacts/instacollab/public/unilives-assets`) folders.
- Boards belong only under `references/`.
- Never mark an asset production-approved unless the individual file exists and was explicitly approved.
- Runtime serves only from `artifacts/instacollab/public/unilives-assets` after validated install.
